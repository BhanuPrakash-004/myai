# Java syntax

This is synthetic demonstration content for importing into a disposable MyAI installation.

A Java class groups fields and methods. An instance field belongs to an object; a static field belongs to the class.

```java
class Counter {
    private int value;

    void increment() {
        value++;
    }

    int getValue() {
        return value;
    }
}
```
